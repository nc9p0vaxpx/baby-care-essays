# 原创语言矫正老师教你一招，有效处理自闭症孩子哭闹打人行为

> 更新时间：2026-09-11 (UTC+8)

自闭症孩子不会说话，想要东西就大哭，如何才能教授孩子正确提出要求的方法呢?作为经验丰富的语言矫正老师，分享一种非常有效的干预策略，能够有效的解决这个难题。

对于这种异常行为问题较多的孩子，我们会使用“地板时光”进行干预。地板时光疗法的出发点就是在双向活动中帮助孩子增强与你互动能力，因为他没有固定的课程而是完全根据孩子的活动兴趣决定训练内容的特点让训练活动更加符合自闭症儿童特点。孩子在他兴趣的活动中更容易与你交流沟通。

例如：

我们接收过这样的案例 高**，4岁1个月，在某康复中心进行康复训练前未上过幼儿园，也未接受过系统的学习，3 岁多时被诊断为自闭症谱系障碍。其自闭症特征明显，存在无意识语言，且攻击性行为问题较为突出，在语言矫正过程中经常出现抗拒学习并伴随哭闹行为，对老师的指令不能自主完成并存在打人行为。

我发现这个孩子每天总是拿着一个绿色的塑料杯子作为玩具，并常常用它来敲桌子。在对他做个训时，我先是看着他独自玩他的塑料杯子，我走进他，和他面对面坐下来，认真地看着他玩，然后大声说：“哇，杯子好漂亮啊，你很喜欢你的杯子吗？”他无视我的关注和问话继续把玩着杯子。

我从身后拿出几粒彩色珠子也放在手上玩着，他看了一眼珠子又转头继续玩杯子，我自言自语，把珠子放到杯子里会怎样呢？随后我把珠子放进他的杯子，并手把手地和他一起摇动杯子。杯子里珠子碰撞发出了动听的声音。他被这种全新的声音所吸引了，不停地晃动杯子，这时我一边拍手一边说，“真好听啊，也让我摇一下。”他把杯子给我摇，我摇完再给他，并且说“轮到你了，你来。”

在这样的一个小游戏之中他学会了从能够看着我摇晃杯子到慢慢地和我有了目光接触，并且懂得耐心等待我摇晃杯子之后他再摇晃，和老师的沟通也越来越多。

在之后的语言矫正训练回合中，我还和他一起玩了滚珠子，夹珠子等的游戏，孩子也从原来的只会紧紧抓住杯子，到后来能够用杯子玩晃动珠子的游戏，到放下杯子主动找我玩各种游戏了。在这一训练中，老师始终遵循了地板时光疗法的几个操作原则。

(1)始终和孩子面对面，让对方看到你的面部表情，听到你的声音,和孩子握着手，并保持目光接触。

(2)老师以孩子正在玩塑料杯子作为介入的基础，从他的喜好和兴趣出发，把自己作为孩子的一个游戏玩伴，在和孩子建立了亲密接触的基础上，通过愉悦的互动，在孩子做出老师期待的行为时，老师不断的表扬与鼓励，让孩子感受成功的喜悦和交往的乐趣。

(3)在摇杯子和拣珠子的游戏中，老师所充当的角色又不仅仅是与孩子游戏的跟随者，老师更是一个有建设性的协助者，和孩子采用轮流的方式互动，让孩子参与、等待、轮流、遵从指令，而这些都是社会交往的基本技能。

干预的结果如何呢？

与干预前相比，孩子的攻击性行为明显减少，在康复中心的哭闹行为目前已经减为 0 次，可谓效果显著。另据家长反馈，小高在课堂外的攻击性行为也明显减少，体现在需求得不到满足时不会再把打人、哭闹作为主要应对方式，而是学会了用言语表达自己的需求。
