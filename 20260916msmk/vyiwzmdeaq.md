**医生**

**家长**

什么？矮小也是病？矮小不过就是给孩子的生活、学习、工作造成不便，最多成为以后孩子升学、求职、婚恋的拦路虎，还能影响健康？

是的，矮小症是多种原因导致的疾病，常见的病因有生长激素缺乏症、甲状腺功能低下、先天性卵巢发育不全综合征、特发性矮身材、小于胎龄儿等。除了矮小，还会影响蛋白质和脂肪代谢，甚至影响智力、性发育等方面。矮小症的早期发现、早期诊断、早期治疗非常重要。

**医生**

**矮小症的发病率高吗？**

  //  

我国儿童矮小发病率约为3%，所有矮小人口中，4-15岁的需要治疗的患儿约有700万。然而，目前我国每年因矮小就诊的患者不到30万名，真正接受合理治疗的患者不到3万名。

据调查，90%的矮小症患儿有不同程度的自卑、抑郁、内向或缺乏领导力等心理或行为障碍，可能影响到升学、就业和婚姻。部分患者甚至不具备正常劳动能力，成为家庭和社会的负担；许多家长不知道矮小可能是一种病理状况，更不知道这类疾病可以干预治疗。

对于孩子长高的问题存在较多认知误区：盲目等待孩子年龄大了后身高会“窜一窜”“猛长”；盲目听信广告宣传，给孩子吃所谓“增高药”、保健补品或使用“物理增高仪”，反而对正规治疗药物生长激素因含有“激素”二字而心存疑虑。

**如何知道孩子是矮小症呢？**

  //  

矮小症是指身高低于同种族、同年龄、同性别正常健康儿童身高的第3百分位，或者低于2个标准差(见上表)。

注意：偏矮是正常情况，不属于矮小症。

**如何判断孩子是否性早熟呢？**

  //  

男孩在9岁以前、女孩在8岁以前出现第二性征发育现象称为性早熟。尤其是女孩，在8岁以前乳房发育或者10岁以前月经初潮，都是性早熟的表现。

**性早熟有哪些危害呢？**

  //  

1、成年终身高受损：性早熟的孩子往往骨龄进展快，从而骨骺提前闭合，孩子生长时间缩短，导致成年后个子不高。

2、与年龄不相应的心理行为问题，如早初潮对心理的影响。

3、社会问题：性行为、性侵犯等。

4、性激素过早作用的远期影响：如成年后子宫、乳腺、睾丸等肿瘤发生率较正常人群偏高。

5、其他：代谢风险，如肥胖、高血糖、高血脂。

**孩子完全无法安静，特好动**

**是多动症吗？该怎么办？**

  //  

“多动症”医学命名“注意缺陷多动障碍”。目前世界公认发病率为5%-10%，近几年来有逐渐上升的趋势。儿童多动症是指发生于儿童时期，具有明显的、持续的注意力不能集中，活动过度、任性、冲动和学习困难为主要特征的一组综合征。

多动症的表现包括活动过多、注意力不集中、行为冲动，以及继发性学习困难。多动症如果不能得到及时治疗，70%带到青少年，50%带到成年，会影响到学习成绩和工作能力，社交、从而降低成人以后的生活质量。如人际关系冲突、家庭关系不和睦、工作力不从心、交通违章等，甚至有酗酒、服毒、自杀、物质滥用、犯罪等风险。
